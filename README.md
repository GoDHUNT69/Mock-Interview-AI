## <a name="introduction">🤖 Introduction</a>

**Prepwise** is an AI-powered web platform designed to help users **practice job interviews** using interactive **AI voice agents**.  
Built with **Next.js**, **Firebase**, and **Vapi**, Prepwise enables full interview sessions, real-time voice interaction, and detailed AI feedback to help candidates improve technical knowledge, communication, and confidence.

---

## <a name="tech-stack">⚙️ Tech Stack</a>

- **Next.js** — React framework for full-stack web apps  
- **Tailwind CSS** — Utility-first styling  
- **Firebase** — Authentication and data storage  
- **Vapi AI** — Voice agent integration  
- **shadcn/ui** — UI components  
- **Google Gemini** — Dynamic question generation  
- **Zod** — Runtime schema validation  

---

## <a name="features">🔋 Features</a>

- **Authentication** — Sign up & sign in with Firebase  
- **AI-Generated Interviews** — Auto-generate questions per role/level/tech stack  
- **Voice-Based Interaction** — Conduct interviews via Vapi voice agents  
- **Instant Feedback** — AI evaluates transcript and returns scores & suggestions  
- **Dashboard** — Track and manage interviews  
- **Responsive Design** — Mobile and desktop ready  
- **Modular Architecture** — Clean components and reusable services
